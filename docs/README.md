# FrontierOS landing (GitHub Pages)

This folder is generated by `python scripts/build_ghpages.py` and published to GitHub Pages.

## Setup

1. Deploy the FastAPI backend somewhere public (Render, Railway, VPS, etc.).
2. In the GitHub repo, set **Settings → Secrets and variables → Actions → Variables**:
   - `FRONTIEROS_API` — backend root URL, e.g. `https://your-api.onrender.com`
   - `FRONTIEROS_APP` — app URL, e.g. `https://your-api.onrender.com/app`
3. Enable **Settings → Pages → Source: GitHub Actions**.
4. Push to `main` (or run the **Deploy landing to GitHub Pages** workflow).

## Local preview

```bash
python scripts/build_ghpages.py
cd docs && python -m http.server 8080
```

Edit `docs/config.js` to point at your API before testing signup from a static server.
